# Photo gallery

The gallery photos are stored in `../images/` and referenced by their relative paths in `index.html`. The current four photo filenames are:

- `photo-01.JPG`
- `photo-02.jpg.JPG`
- `photo-03.jpg.JPG`
- `photo-04.jpg.JPG`

The filename and letter case in each `src` must match the actual image file, especially after publishing because hosting servers use case-sensitive paths. If you add or rename photos, update the matching `src` in `index.html`. Replace each image's `alt` text with a short description of the photo. Use photos you have permission to publish, especially when people or trainees are identifiable.
